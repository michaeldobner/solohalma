## Projekt auf einen Blick

* **Spiel:** Solohalma (Solitär) auf dem englischen Kreuzbrett mit 33 Feldern
* **Plattform:** Progressive Web App, optimiert für iPhone und iPad, läuft in jedem modernen Browser
* **Technik:** HTML, CSS und JavaScript (ES-Module), SVG-Grafik, kein Framework, kein Build-Schritt
* **Betrieb:** GitHub Pages, offline spielbar über einen Service Worker
* **Live:** https://michaeldobner.github.io/solohalma/
